# 🐤 Flappy Bird (Python)

A Python-based recreation of the classic **Flappy Bird** game, built using **Pygame** to demonstrate real-time game loops, collision detection, and event-driven programming.

The project focuses on **clean game mechanics and responsive controls**, rather than graphics complexity.

---

## 🎮 Gameplay Overview

- Control the bird to fly through gaps between pipes
- Each successful pass increases the score
- The game ends when the bird collides with a pipe or the ground
- Restart and game-over screens allow replay without restarting the program

---

## ✨ Features

- Smooth and responsive game mechanics  
- Pixel-style Flappy Bird visuals  
- Real-time scoring system  
- Restart and Game Over handling  
- Event-driven game loop using Pygame  

---

## 🧠 Core Concepts Demonstrated

- Game loop design  
- Collision detection  
- Keyboard event handling  
- Sprite movement and gravity simulation  
- Frame rate control for smooth gameplay
